# ORION FORGE

**Build Apps, Games & AI from Text. 0MB Install.**

ORION FORGE turns plain English into live websites, HTML5 games, and PWAs in 10 seconds. No signup. No code. 

### Features
- 🤖 **AI & Chatbots** - Personal assistants, PDF tools, roast bots
- 🎮 **Games** - Flappy Bird, Snake, 2048 in 1 click  
- 🛠️ **Tools** - QR generators, crypto trackers, utils
- 🌐 **Websites** - Landing pages, portfolios
- 📱 **0MB PWA** - Add to home screen. Works offline.
- 🔑 **BYOK** - Use your Groq/Gemini key. We never see it.
